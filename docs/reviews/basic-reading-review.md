검토일: 2026-11-15. 적용 기준은 공개 저장소 `manofin/fortune-oracle`의 `main` 커밋 `2f10b1ee25127f8930082b5b8afd9e34b7603eac`입니다. 이 변경은 한국어 기본 일일 풀이를 검토하기 위한 초안이며, main 반영·서비스 배포·상품 출시를 뜻하지 않습니다.

## 변경 내용과 검토 자료

기존의 “말과 표현이 잘 풀리는 날” 같은 예고형 문구를, 계산 관계에 따른 성찰 주제로 바꿨습니다. 쉬운 해석 → 해볼 일 → 주의할 점 → 계산 근거 → 해석의 한계 순서로 배치했습니다. 내일과 선택일에도 쓰는 엔진이므로 “이날의 해석”, “해볼 일”처럼 날짜에 중립적인 제목을 사용합니다.

- 오행 두 개는 이 점수 규칙의 선택임을 표시하고, 동률이면 목·화·토·금·수 순서로 선택한다고 설명합니다. 정밀한 용신 판단으로 표현하지 않습니다.
- 대운이 없을 때는 계산 결과에서 적용할 구간을 확인하지 못했다고만 설명합니다. 입력 누락 등의 원인을 추측하지 않습니다.
- 계산 알고리즘·점수·등급은 유지합니다. 영어 문구는 기존 localization이 별도로 생성하므로 이번 개선 대상은 한국어입니다.
- 계산된 오행·일진·대운은 계산 결과입니다. 관계를 성찰 주제로 연결한 문장과 행동은 규칙에 따른 해석·예시입니다. 고객이 제공한 실제 생활 사실은 없습니다. `used_evidence` 같은 항목 매핑이 있더라도 해석의 타당성을 입증하는 것은 아닙니다.

## 기본 풀이 평가: 보완

자동 테스트와 별도로 AI 검토자가 코드 및 가상 출력을 읽었습니다. 실제 사용자 대상 가림 평가는 아직 진행하지 않았습니다. 담당자별 수락·진행 여부를 이 기록으로 대신하지 않습니다.

읽기 검토에서 확인한 개선:

- 짧은 행동이 계산 설명보다 먼저 나오고, 주의점과 분리됐습니다.
- 사용자의 실제 성격·상황·미래를 안다는 표현을 줄였습니다.
- 오행 선택과 동률 처리를 출력의 계산값과 대조할 수 있습니다.

남은 쟁점:

- 관계가 같으면 같은 해석·행동을 반복합니다. 5관계 문구가 다르다는 테스트만으로 개인화의 충분함을 판단할 수 없습니다.
- “주제로 읽습니다”, “기준 하나” 등이 설명서처럼 느껴질 수 있습니다. 생활에서 도움이 되는지는 읽기 평가가 필요합니다.
- 기존 등급 “아주 좋은 날”, “순풍”은 여전히 예측처럼 읽힐 수 있습니다. 점수 의미와 함께 후속 문구 검토가 필요합니다.
- 해석 근거는 관계·오행 선택·대운을 설명하지만 전체 점수 산식을 모두 풀어쓴 설명은 아닙니다.
- 웹 상세는 한 문단 요소 안에 줄바꿈으로 표시합니다. 행동과 주의는 접힌 상태에서 보이지 않습니다. 구조화된 소제목과 앞쪽 행동 배치를 후속 UI 검토 대상으로 둡니다.

## 사람의 평가 기준 제안 — 아직 합의되지 않음

사람의 응답을 받기 전에 아래 기준과 통과선을 확정해야 합니다. 이 문서는 제안이며 통과 판정을 미리 내리지 않습니다.

| 평가 축 | 기록 방법 | 통과선 제안 |
| --- | --- | --- |
| 이해하기 쉬움 | 각 글 1~5점 + 이해되지 않은 문장 | 변경 후 중앙값 4 이상 |
| 행동 실행 가능성 | 각 글 1~5점 + 부담스러운 행동 | 변경 후 중앙값 4 이상 |
| 근거의 납득도 | 각 글 1~5점 + 계산값과 문구의 연결 설명 | 변경 후 중앙값 4 이상; 경험적 타당성 입증과 구분 |
| 개인적으로 느껴지는 정도 | 각 글 1~5점 | 별도 기록, 근거 점수와 합산하지 않음 |
| 상황·미래 단정 | 문제 문장과 이유 | 확인된 문제는 수정 후 재검토 |
| 모바일 탐색성 | 해석·행동·주의를 찾는 과정 관찰 | 가로 넘침·겹침 없음 + 원하는 항목 찾기 확인 |

초기에는 서로 다른 평가자 5명 이상을 모집하는 방안을 제안합니다. 이는 사용성을 찾기 위한 소규모 검토이며 통계적 효과 입증이 아닙니다. 평가자에게 버전 대응표를 주지 않고, 각 쌍에서 X/Y/차이 없음/판단 어려움을 독립적으로 기록합니다. 현재 자료는 두 사례의 순서를 상쇄했으며 무작위 배정 실험을 실행하지 않았습니다. 읽기 품질 합격·고민의 기여·구매 의향·결제 전환율은 모두 **미측정**입니다.
