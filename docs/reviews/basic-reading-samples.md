# 기본 풀이 전후 샘플

이 자료는 전부 가상 성인 입력입니다. 고민·외부 모델·고객 자료를 사용하지 않았습니다.

기준: 공개 `main` 커밋 `2f10b1ee25127f8930082b5b8afd9e34b7603eac`. 변경 후는 이 문서와 함께 검토하는 변경분입니다.

재생성: `python scripts/build_basic_reading_review.py` (기본 Node 의존성 필요).
자동 비교: 가상 프로필 2개 × 30일 × 5영역 = **300건**, 문구 외 모든 반환 필드 동일.

점수 유지 확인은 문장의 효용이나 점술의 예측 타당성을 검증한 결과가 아닙니다.

| output | 이날의 해석: 생각을 짧고 분명하게 전하는 주제로 읽습니다. | 해볼 일: 전할 말 하나를 짧게 적고 보내기 전에 읽어 보세요. | 주의할 점: 표현이 잘 통할 것이라 가정하지 말고 상대의 뜻을 확인하세요. |
